# Book and Stay (book&stay)

A premium African luxury accommodation and safari platform prototype, inspired by modern Airbnb design patterns, tailored specifically for safari lodges, luxury tented camps, beachfront villas, and unique stays across East Africa and Africa.

## Features
- **Cinematic Property Showcases:** High-resolution galleries and video walkthrough tours.
- **Interactive Search & Map:** Split-view layout with custom live price pins on Leaflet maps.
- **Direct Lodge Inquiries (Option B):** 0% booking commission model where guest inquiries are delivered directly to lodge reservations teams.
- **Partner Onboarding Portal:** Transparent flat membership plans in UGX (Monthly & Annual).
- **Experiences & Lodge Services:** Hot-air ballooning, gorilla trekking, private 4x4 charters, bush chefs, and wellness spas.

## Tech Stack
- React 18 + Vite
- Tailwind CSS
- Lucide React Icons
- Leaflet + React Leaflet
